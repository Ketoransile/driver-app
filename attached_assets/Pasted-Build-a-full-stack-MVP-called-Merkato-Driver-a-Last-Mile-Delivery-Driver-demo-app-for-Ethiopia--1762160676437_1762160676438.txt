Build a full-stack MVP called “Merkato Driver” — a Last-Mile Delivery Driver demo app for Ethiopia.
The system has:

Expo React Native (TypeScript) for the mobile app

Express.js (TypeScript) for the mock backend

No database (use constant data only)

Simulated authentication

Integrated maps showing delivery routes from Addis Ababa to various Ethiopian cities (Nekemte, Shashemene, Jimma, Hawassa, etc.)

Fancy modern dark-themed UI

⚙️ Tech Stack

Frontend: Expo + React Native (TypeScript)

Backend: Express.js (TypeScript)

Data: Constant arrays (no DB)

Styling: NativeWind (Tailwind for RN) or React Native Paper

Maps: react-native-maps (Expo compatible)

Icons: @expo/vector-icons

Navigation: Expo Router with tab navigation

2️⃣ Endpoints

POST /api/auth/login → check username/password → return mock JWT + driver info

GET /api/deliveries/:driverId → return driver’s deliveries

PATCH /api/deliveries/:id/status → update delivery status in memory

📱 Frontend Requirements

1️⃣ Login Screen

Username + Password inputs

Calls /api/auth/login

On success → store token in AsyncStorage → navigate to Dashboard

Invalid → show Alert

2️⃣ Dashboard Screen

Show driver name + status toggle

Display small stats (active deliveries, completed, cities)

Map centered on Addis Ababa (lat: 9.03, lng: 38.74)

Marker for driver location (mocked)

Button → “Go to Deliveries”

3️⃣ Deliveries Screen

Fetch /api/deliveries/:driverId

List deliveries as modern cards with Ethiopian style colors

Tap → go to Delivery Detail

4️⃣ Delivery Detail Screen

Shows recipient info, city, address, phone, and map route

Map displays route from Addis Ababa → destination city using markers + polyline

Buttons:

“Start Delivery” (sets status to In Transit)

“Mark as Delivered”

“Call Recipient” (via Linking.openURL('tel:...'))

5️⃣ Profile Screen

Driver details + rating stars + total deliveries

Logout button (clears AsyncStorage + navigates to login)

🎨 UI / UX Requirements

Dark theme with gradients and Ethiopian color accents (green, yellow, red in subtle tone)

Modern logistics look — smooth cards, shadows, rounded corners

Use NativeWind for Tailwind-style responsive layout

Include animations on button presses and navigation

Bottom Tab Navigation: Dashboard | Deliveries | Profile

Splash screen with logo “Merkato Driver”

🚀 Commands

Use concurrently to run both servers:

Frontend: Expo Dev on port 8081

Backend: Express server on port 5000

npm run dev → runs both
